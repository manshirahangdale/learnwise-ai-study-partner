# LearnWise – AI Study Partner

## Team: Learnlytics

## Project Overview
LearnWise is an AI-based study partner that analyzes student quiz performance to identify learning gaps and generate personalized study recommendations.

## Problem Statement
Students often fail to identify their weak areas and spend time studying inefficiently without focusing on topics that need improvement.

## Proposed Solution
The system collects quiz performance data such as accuracy, time taken, and difficulty level to detect weak topics using machine learning techniques.

## Key Features
- Quiz-based performance analysis  
- Learning gap detection  
- Personalized study recommendations  
- Generic across multiple subjects  

## System Flow
1. User registers and selects subjects  
2. User takes quizzes  
3. System analyzes performance  
4. Weak topics are identified  
5. Study recommendations are generated  

## Tech Stack
- Python  
- Pandas  
- Scikit-learn  
- Streamlit (for UI)
